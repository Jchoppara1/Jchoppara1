3) CALIBRATION / RESCALING (MAKE IT CLEAR-CUT)
--------------------------------------------
Implement a calibration function that maps rawScore -> matchScore (0–100) with more separation:

Step 1: Standardize within each dish
- For a given dish, you have N candidate wines with rawScore.
- Compute mean and std (or robust median and MAD).
- Compute zScore = (rawScore - mean) / std  (or robust equivalent).
- This makes the distribution per dish comparable.

Step 2: Convert zScore -> percentage using a logistic curve to spread mid-scores:
- p = 100 * sigmoid(k * zScore)
- Choose k around 1.2–1.8 so top options become meaningfully higher than mid pack.
- Clamp p to [1, 99] to avoid hard 0/100.

Step 3: Add a “top-pick boost” so the best pairing feels decisive:
- Sort wines by rawScore for the dish.
- Add small boost to rank #1 and #2 only (e.g., +6 for #1, +3 for #2) BUT cap at 99.
- Add a penalty if any “hard mismatch rules” triggered (e.g., -8 to -20 depending on severity).
This ensures obvious mismatches don’t show high percentages.

Step 4: Optional global calibration
- Across the full wine list, track percentiles of zScore or p and ensure:
  - top pick is often 88–97
  - second pick 80–92
  - third pick 72–88
  - mid pack 45–70
  - poor fits 15–44
Adjust k and boosts until this holds for typical menus.
