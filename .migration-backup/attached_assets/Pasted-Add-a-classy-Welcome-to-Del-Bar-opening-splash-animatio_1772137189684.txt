2) SPLASH COMPONENT
------------------------------------------------------------
Create a new component: src/components/SplashIntro.tsx

Behavior:
- Show splash overlay on first app load.
- Duration: ~2.2 seconds total.
- Then fade out smoothly and reveal the app underneath.
- If user has prefers-reduced-motion, shorten duration and remove heavy motion (simple fade).

Content:
- Center title: “Welcome to Del Bar”
- Subtitle (small): “Middle Eastern • Mediterranean”
- Animated color sequence using existing theme tokens:
  - background starts on warm sand (bg-background)
  - a blush wash passes (use token blush if you have it, otherwise muted/secondary)
  - an olive accent line draws across (primary)
  - a thin gold highlight line appears (gold token or ring color)
- Food image carousel behind/alongside text:
  - Crossfade between images every ~650ms (2–3 transitions total).
  - Apply a tasteful dark/blur overlay so text is always readable.

Premium details:
- Use subtle grain/texture overlay at very low opacity (optional).
- Use slow scale on images (1.02 → 1.05) for cinematic feel.
- No janky jumps; only opacity/transform transitions.

3) WHERE TO TRIGGER IT (APP ENTRY)
------------------------------------------------------------
In your main entry layout (App.tsx or root layout component):

- Render <SplashIntro /> above everything with fixed positioning and high z-index.
- Block interaction while splash is visible (pointer-events).
