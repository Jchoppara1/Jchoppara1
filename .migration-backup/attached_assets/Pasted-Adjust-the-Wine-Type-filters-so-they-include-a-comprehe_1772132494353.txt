------------------------------------------------------------
3) CLASSIFICATION RULES (DETERMINISTIC + PRECEDENCE)
------------------------------------------------------------

Step A: Normalize all searchable text
- Lowercase
- Remove diacritics
- Combine name + region + style + notes + grapes into one searchable string

Step B: Explicit keyword detection (highest precedence)

Sparkling keywords:
champagne, cava, prosecco, franciacorta, sekt, cremant, spumante, pet-nat, pet nat

Rosé keywords:
rosé, rose

Orange keywords:
orange, skin-contact, skin contact, ramato

Fortified keywords:
port, porto, sherry, madeira, marsala, vermouth, vin doux naturel, banyuls, rivesaltes

Dessert/Sweet keywords:
late harvest, icewine, sauternes, tokaji, beerenauslese, trockenbeerenauslese, passito, vin santo, demi-sec, doux

Non-alcoholic keywords:
non-alcoholic, dealcoholized, 0.0

Step C: Region inference (strong fallback)

Champagne -> sparkling
Prosecco / Conegliano Valdobbiadene -> sparkling
Cava / Penedès -> sparkling
Sauternes / Tokaj -> dessert
Jerez / Montilla-Moriles / Madeira -> fortified

Step D: Grape-based inference

If grapes include common red varieties:
cabernet sauvignon, merlot, pinot noir, syrah, shiraz, grenache, tempranillo, sangiovese, nebbiolo, malbec, zinfandel, barbera, mourvedre, gamay, carmenere

→ typePrimary = red

If grapes include common white varieties:
chardonnay, sauvignon blanc, riesling, pinot grigio, pinot gris, chenin blanc, albariño, grüner veltliner, viognier, semillon, gewurztraminer, muscadet, vermentino, torrontes, garganega, arneis, trebbiano, fiano

→ typePrimary = white

Step E: Language hints

“rouge” or “rosso” → red  
“blanc” or “bianco” → white  

Avoid guessing rosé unless explicitly stated.

If uncertain, choose best-supported type and set confidence lower.

Return reasons like:
"keyword:champagne"
"grape:cabernet sauvignon"
"region:sauternes"
